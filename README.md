
## Ejecución del proyecto

Para restaurar las dependencias:

```bash
dotnet restore
```

Para ejecutar la aplicación:

```bash
dotnet run
```

Para ejecutar las pruebas automatizadas:

```bash
dotnet test Tests/CleanCodeVentas.Tests.csproj
```

## Pruebas automatizadas

El proyecto utiliza xUnit para verificar el comportamiento de los servicios mediante pruebas unitarias con el patrón Arrange, Act, Assert (AAA).
